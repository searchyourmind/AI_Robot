# Requirements and assumptions — 12 V redesign

**PROVISIONAL DESIGN — ACTUAL ROBOT COMPATIBILITY NOT VERIFIED.**
**DRAFT — NOT RELEASED FOR FABRICATION.**

The user authorized a native KiCad redesign for the purchased 12 V motor system. The current architecture uses four DRV8874PWPR bridges and a TPS26630 eFuse/reverse-blocking input path. Native generation and routing are complete; final ERC, DRC, unconnected and schematic-parity checks each report zero for the exact inputs in the [check report](../validation/design/design_check_report.md). No earlier ERC/DRC result is transferred to the changed circuit. The current manifest contains 135 schematic items, including 14 copper testpoints, and 121 intended fitted components across seven schematic sheets. Final counts and check results belong to the new [progress record](../PROGRESS.md) and design reports.

The completed earlier 5.5–6.5 V reference is frozen in [rev_a_6v_archive](../../rev_a_6v_archive/README.md). Its accepted assumptions, copper geometry and reports remain historical evidence. The new 9–15 V envelope and 100 × 100 mm outline below are engineering assumptions for the redesign; they are not newly measured battery or chassis facts.

**Evidence labels:** USER-CONFIRMED records what the user reported; PURCHASE-RECORD CONFIRMED records a supplied listing; CODE ONLY describes repository constants; ASSUMED — REDESIGN identifies a chosen design boundary; DERIVED identifies a calculation or interface requirement; UNKNOWN identifies an unresolved real-system fact. None of these labels means physical validation.

## Remaining evidence and status

Actual compatibility still needs motor identity/current/torque, pack voltage and protection behavior, the installed power graph, both boards' real GPIO/VCC wires, motor polarity and mechanical fit. Encoder voltage/pinout/count convention becomes a further requirement if an encoder interface is requested. The [12 V impact review](12v_design_impact.md) preserves why the earlier board was rejected for direct 12 V input; it is historical context for this redesign, not a claim that the new circuit is already verified.

Fabrication: **DEFERRED / NOT BUILT**. Assembly: **DEFERRED / NOT ASSEMBLED**. Physical validation and proposed-PCB integration: **NOT TESTED**. Native checks and their exact inputs are reported separately; clean CAD does not resolve the unknown real-system facts above.
